# Sourav Das Portfolio

A dark, technical portfolio built with React + TypeScript + Vite.

## Stack
- React
- TypeScript
- Vite
- CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Personal data used
The content is based on the uploaded Sourav Das CVs. No fictional employer, certification or project has been added.
